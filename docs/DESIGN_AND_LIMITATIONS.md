# Nemo Next · AS2 交互原型

依据用户提供的「Nemo_AS2_交互与设置_讨论版」整合制作。这是适用于下载后本地运行的独立版本。

## 启动与访问

请按仓库根目录 README.md 操作。本仓库提供完整网页和约 20 MB 的视频演示版。

## 使用场景

做饭等不方便频繁触屏时按内容定位和循环；通过语音解说了解画面；通过台词、声音提示和声源标注辅助理解声音。用户不需要选择残障身份，所有辅助功能可组合使用。

## 三条完整演示流程

1. 语音控制：选「跟着做一道菜」→ 点击示例「回到打蛋，循环这一步」→ 真实视频到 00:55 并在 01:01 前后循环 →「下一步」进入调料片段并继续循环 →「继续播放」退出循环。也可输入「跳转到加入调料」，从多个做法中选择；第一种调料在 01:01，第二种在 03:06。
2. 画面理解：选「听见画面里的故事」→ 播放动画 →「画面里有什么」→ 动画暂停、显示并朗读预设描述 →「为什么好笑」→ 解释声画联系 →「继续播放」恢复动画并结束问答。
3. 点选辅助：选「发现声音的踪迹」→ 点 Nemo 球 → 开启 B 场景音效 → 关闭设置 → 暂停时长按鸟、钟楼或车辆声源（默认 0.6 秒），键盘 Enter/空格也可打开 → 关闭批注 → 播放 → 显示简短音效提示。A 支持空间气泡/底部字幕；C 在动画播放时提供独立视觉节拍，暂停时停止。

## 设置中心

球 → 快捷设置 → 全部设置；也可点页面上的「个性化你的 Nemo」。完整设置在对话框内独立滚动，返回视频保留播放位置。菜单包含 12 页。偏好用当前浏览器 localStorage 的 `nemo-next-settings-v1` 保存。

已接通：A/B/C 开关、字幕布局/说话人/字号/底色、声源标注/长按时长、音乐描述、视觉节拍、主题、较大文字、减少动态、球大小、语音开关/确认/语速/超时/连续对话、画面解说详细程度/开场介绍、原声降低、片段默认播放行为、球旁执行反馈、简短回复。父开关关闭后保留子设置。清除偏好前需确认。

概念选项：自动表达偏好学习、对话历史、产品改进、账户同步、声音风格、真实触觉与触觉强度。不会训练、上传、同步或震动。这些选项仅保存选择或提供预览。详细回复为固定文字，不是生成式写作。

## 真实语音

点击麦克风后浏览器才会申请权限。默认开启唤醒词：授权后说「嘿 Nemo」，接着说指令；可一次说「嘿 Nemo，回到打蛋，循环这一步」。也可在设置关闭唤醒词，直接说指令。

支持浏览器提供的 SpeechRecognition / webkitSpeechRecognition 与 speechSynthesis；浏览器可能联网处理语音。Nemo 不保存录音、不上传音视频至自建后台。再次点击麦克风、切换场景、打开对话框、页面进入后台或无输入超时会停止监听；已开始的循环保留（切换场景会重置播放）。页面隐藏会暂停视频。

不支持语音识别或权限/网络出错时显示具体反馈，仍可文字输入与示例演示。网页不能保证后台常驻唤醒。首次启动、权限及真实识别准确率需在实际设备人工验证，不能用点击示例代替语音实测。

## 实现与素材

- 原生 HTML/CSS/JavaScript，独立设置 iframe 通过同源且校验来源的 postMessage 与播放器同步。
- HTMLVideoElement 控制真实播放、定位、循环；独立计时器驱动 SVG 动画演示。
- 做饭视频来自用户已有缓存，美食作家王刚R「番茄炒蛋的6种做法」，BV1Py4y1S7EF。视频源 https://www.bilibili.com/video/BV1Py4y1S7EF/ 。音视频已无损合并；未重新下载视频。
- 小猫与街景 SVG、设置界面及 Nemo 球形状源自用户提供的讨论版 HTML，整合时补上播放器设置联动。
- 时间段与关键词在 `dist/data.js`；纯指令匹配在 `dist/core.js`；主交互在 `dist/app.js`。

## 明确限制

- 不是通用 AI 视频理解。做饭步骤是人工标注；画面问答、音效、字幕与节拍使用预设场景数据。未知指令不执行猜测性跳转。
- 做饭视频目前显示动作提示，不是完整人声转录；没有其场景音效定位标注。
- 两个动画场景没有真实音轨，台词和音乐文字是演示。C 仅是按演示节奏的视觉提示，无实际音频节拍提取或设备震动。
- 时点为人工近似标注，不代表逐帧精度。复杂自由问答尚未接入。
- 尚未做真实目标用户无障碍测试或屏幕阅读器完整审计；支持基本键盘、可读控件名称、原生模态框、减少动态和字幕替代。声源支持键盘替代长按。
- 本地运行地址不等于可跨设备访问的提交链接，正式提交前需另行安排可访问的托管或现场运行方式。
